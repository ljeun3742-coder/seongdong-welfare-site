# 성동구 복지도우미

무엇이 필요한지 잘 몰라도 괜찮은 **성동구 복지정보 안내 사이트**입니다.
몇 가지 질문에 답하거나 직접 검색하면, 도움이 될 만한 복지제도와 성동구 복지관·센터를 찾아 보여 줍니다.

- 사이트 주소: https://ljeun3742-coder.github.io/seongdong-welfare-site/
- 로그인 없이 이용할 수 있고, 개인정보를 받지 않습니다. (상담 신청 양식은 별도 설정을 켠 경우에만 열립니다.)

> ⚠️ **시연용 초안입니다.** 이 사이트는 복지 지원 **자격을 판정하지 않습니다.** 정확한 대상 여부와 신청은
> 보건복지상담센터 **129**, 거주지 주민센터, [복지로](https://www.bokjiro.go.kr), [성동구청](https://www.sd.go.kr)에서 확인해 주세요.
> 운영 시간·프로그램·모집 시기는 바뀔 수 있으니 방문 전에 기관에 전화로 확인해 주세요.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 💬 질문하며 따라가기 | "어떤 복지정보가 필요하신가요?"에서 분야(긴급·경제·식사·이동·관계·복지관)를 고르고 1~2개 질문에 답하면 관련 안내를 보여 줍니다. |
| ❔ 도움 검색 | "어떤 도움을 받을 수 있는지 모르겠어요"를 누르면 검색창이 열립니다. 복지제도·복지관·행사·연령별 안내를 한 번에 찾고, 비슷한 말(예: 밥 → 식사·반찬)도 함께 찾습니다. |
| 🎂 연령별 정보 | 영유아부터 어르신까지 나이대별 지원과 복지관 프로그램을 모아 보여 줍니다. |
| 🏠 복지관·센터 안내 | 종합사회복지관, 노인복지관 8곳, 1인가구지원센터, 정신건강복지센터, 서울잇다플레이스 등의 주소·전화·오시는 길·프로그램. |
| 📅 복지관 행사 | 앞으로 열릴 행사를 달력으로 확인합니다. |
| 🚌 성공버스 시간표 | 정류장을 고르면 노선별 도착 시각표를 보여 줍니다. |
| 🍚 밑반찬·식당 | 식사 준비가 어려운 분을 위한 급식지원, 복지관 밑반찬, 경로식당 안내. |
| 🔊 읽어주기 | 화면 내용을 소리로 읽어 줍니다. 상담 양식에는 말로 입력하는 기능도 있습니다. |
| 가+ 글씨 | 글자 크기를 키울 수 있습니다. |

## 이렇게 만들어져 있어요

별도의 설치나 빌드가 필요 없는 **정적 사이트**입니다. (HTML + CSS + JavaScript, 외부 라이브러리 없음)

```
index.html            화면 틀(머리글·본문·하단 버튼)
style.css             모양
app.js                화면 동작과 내장 복지 데이터(제도·복지관·행사 등)
supabase-config.js    Supabase 연결 설정 (공개용 키만 들어 있음)
supabase/             데이터베이스 표 만들기·내용 추가·수정용 SQL 파일과 연결 안내
google-sheets/        상담 신청을 구글시트로 받을 때 쓰는 Apps Script와 설정 안내
```

### 내용은 어디에서 오나요?

1. 사이트 안(`app.js`)에 **기본 내용**이 들어 있어서, 인터넷 데이터베이스가 없어도 정상 동작합니다.
2. `supabase-config.js`에 Supabase 주소와 공개용 키가 있으면, 사이트가 열릴 때 **데이터베이스의 내용을 우선** 사용합니다.
   읽지 못하면 자동으로 기본 내용으로 돌아갑니다.

> **그래서 복지관·프로그램 내용을 고칠 때는 `app.js`와 Supabase를 둘 다 고쳐야 합니다.**
> 한쪽만 고치면 DB에 연결된 사이트에서는 바뀐 내용이 보이지 않거나, 연결이 끊겼을 때 옛 내용이 나옵니다.

## 내용 고치기

- **Supabase 연결과 SQL 실행 방법**: [`supabase/연결-안내.md`](supabase/연결-안내.md)
- `supabase/add-*.sql` 파일은 여러 번 실행해도 안전합니다. `supabase/seed.sql`은 **처음 한 번만** 실행하세요
  (다시 실행하면 대시보드에서 고친 내용이 처음으로 돌아갑니다).
- 행사 추가: `app.js`의 `events` 목록(또는 Supabase `events` 표)에 한 줄 추가합니다. 공식 출처를 확인한 일정만 넣어 주세요.
- 검색에서 찾는 비슷한 말 추가: `app.js`의 `SEARCH_SYN`에 한 줄 추가합니다.

## 상담 신청 (선택 기능)

개인정보 보관 기간 문구(`retention`)가 `supabase-config.js`에 채워져 있을 때만 상담 신청 양식이 열립니다.
신청은 Supabase 또는 구글시트로 받을 수 있습니다. 설정 방법은 [`google-sheets/설정-안내.md`](google-sheets/설정-안내.md)와
[`supabase/연결-안내.md`](supabase/연결-안내.md)를 보세요. 운영하기 전에 기관과 보관·삭제 기간, 신청 확인 담당자, 만 14세 미만 보호자 동의 여부를 정해야 합니다.

## 보안 · 개인정보 주의

- 사이트 파일에는 **공개용(anon/publishable) 키만** 넣습니다. **`service_role` 키는 절대 넣지 마세요.**
- 방문자는 복지 정보를 **읽기만** 할 수 있고, 수정은 Supabase 대시보드에서만 가능합니다(`supabase/schema.sql`의 권한 설정).
- `.env.local` 같은 비밀 파일은 저장소에 올리지 않습니다(`.gitignore`).
